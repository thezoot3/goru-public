# 고루 (Goru) 기술 문서

고루는 iPad 전면 카메라로 손끝과 얼굴 피부의 접촉을 추정하고, 접촉 위치를 얼굴 위에 기록해 자외선 차단제 도포를 돕는 XR 코칭 앱이다. 직접 수집한 데이터로 학습한 온디바이스 CNN을 사용하며, 인식과 기록은 기기 안에서 수행하고 영상을 외부로 전송하지 않는다.

배포 빌드 기준으로, 카메라 영상은 기기 밖으로 보내지 않고 기기에도 저장하지 않는다. 남는 것은 프로필별 도포 기록뿐이며 서버와 온라인 계정이 없다. 개발·평가용 진단 빌드는 프레임을 저장하며, 이 기준의 예외다.

기록은 얼굴 UV 좌표계에 누적해 머리 방향이 바뀌어도 같은 피부 지점에 대응하도록 한다. 자외선 차단제의 존재, 도포량, 차단 효과를 직접 측정하는 기능은 아니다.

앱은 프로필을 선택해 프로필별로 도포 기록을 남기고, 엄지척 제스처 1초 유지로 세션을 시작·종료한다(보호자는 화면 버튼으로도 시작·종료할 수 있다). 코칭 화면은 덜 바른 부위를 가리키는 안내를 표시하고, 결과 화면에서 기록을 저장하거나 이어서 바를 수 있다. 앱 기능의 전체 흐름은 공모전 보고서 4절에서 다룬다.

이 저장소는 공모전 보고서 본문(2026년 9월 제출본)을 보완하는 기술 문서 모음이다. 앱 소스 코드, 학습 데이터와 모델 가중치는 포함하지 않는다.

## 파이프라인 개요

| 단계 | 구성 |
|---|---|
| 입력 구성 | MediaPipe hand/face landmark → fingertip crop → rotation/scale normalization → 5채널 입력 |
| 접촉 판정 | Core ML CNN → 세션별, 손가락별 running z-score normalization → 접촉/비접촉 판정 |
| 위치 기록 | 얼굴 표면 좌표(UV 맵) 변환 → 128×128 텍셀에 0~1 누적 → 0.35초 이하 끊김은 기록에서 이음 |

Landmark는 CNN이 볼 손끝 주변 영역을 정하고, CNN 판정은 접촉 위치를 기록할지 결정한다. [모델카드](MODEL_CARD.md)는 판정 성능을, [실기기 성능](PERFORMANCE.md)은 실행 비용을 설명한다.
